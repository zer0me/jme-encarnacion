# Archivo público — Junta Municipal de Encarnación

Archivo ciudadano de actas, minutas, resoluciones, dictámenes e informes de gestión de la **Junta Municipal de Encarnación** (Paraguay), organizado para que cualquier vecino, periodista o estudiante pueda responder la pregunta **«¿qué pasó con esto?»** sin tener que leer 600 PDFs.

🌐 **Sitio público:** https://zer0me.github.io/jme-encarnacion/

📋 **Dashboard de entrada:** [DASHBOARD.md](./content/DASHBOARD.md)

## Qué hay acá

- **261+ documentos curados** con frontmatter estructurado: 176 actas (2021-2025), 72 minutas de comisiones, 9 resoluciones, 4 informes de gestión.
- **431+ fichas de entidades**: concejales, instituciones, empresas, normativa, temas.
- **12 Mapas de Contenido (MOCs)** que cruzan documentos por tema institucional: lobbycracia y captura regulatoria, cambio de Mesa Directiva 2024, ordenanzas urbanísticas en bloqueo, concesión RSU, plan urbano POUT, movilidad alternativa, carnavales y turismo, DINAC y aeropuerto, vendedores ambulantes, y más.

## Cómo navegar

Empezá por el **[DASHBOARD](./content/DASHBOARD.md)**. Tiene tres entradas según para qué venís:

- 🏛️ **Vecinos** — qué está pasando en la JM, temas calientes, quiénes son los concejales.
- 📰 **Periodistas** — patrones institucionales detectados, votaciones controvertidas, plata pública asignada, hilos abiertos para investigar.
- 🛠️ **Operativo** — métricas del vault, estado de los MOCs, pendientes de procesamiento.

## Tecnología

- Las notas están en formato Markdown con [wikilinks de Obsidian](https://obsidian.md).
- El sitio público se genera con [Quartz v4](https://quartz.jzhao.xyz) — buscador, graph view y backlinks nativos.
- Despliegue automático a GitHub Pages vía GitHub Actions en cada `push`.
